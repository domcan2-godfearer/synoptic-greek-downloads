# Synoptic Greek Interlinear Bible Downloads

Official standalone v1.1.12 installers for Windows x64, Ubuntu amd64 and Android ARM64.

[Download page](https://domcan2-godfearer.github.io/synoptic-greek-downloads/)

[Release notes and installer assets](https://github.com/domcan2-godfearer/synoptic-greek-downloads/releases/tag/v1.1.12)

The public repository contains the download page and release installers. Application development remains in the private source repository. GitHub's automatically generated source archives here contain the download page, not the Bible reader project.

See [SHA256SUMS.txt](SHA256SUMS.txt) for installer hashes. All three uploaded assets match the original v1.1.12 validation record.

Ubuntu requires x86-64, Ubuntu 24.04 or newer, glibc 2.39 and WebKitGTK 4.1. Windows requires WebView2; the installer is not Authenticode signed. Android uses ARM64 and retains the existing package and signing identity.

## Updating this page

Upload and verify a new release's installer assets before changing the page's version and direct download links. Keep platform requirements, file sizes, release notes and checksums in sync. Pages deploys from the main branch root. No JavaScript or external dependencies are required for downloads.
