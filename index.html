Inside this release

More words to work with.

Version 1.1.12 adds English glosses to 1,831 LXX word occurrences since the 1.1.9 installers, bringing measured LXX gloss coverage to 90.02%. Unconfirmed suggestions stay visibly separate from confirmed glosses.

Read, inspect, compare

Navigate by book, chapter and verse. Tap a Greek word to inspect lexical details and explore lemma connections, then return to your reading position.

Study offline

The installed reader includes its Bible corpus, lemma indexes, dictionaries and fonts. Ubuntu may need an internet connection to install system dependencies.

Before you install

Updating an existing installation

Close the reader before running the installer. Android v1.1.12 retains the existing package ID and signing certificate, with an increased version code. Device testing is still useful: package checks do not confirm every phone or desktop configuration.

Installing on Android

Download the APK, open it, and allow installation from the browser or file manager if Android prompts you. After installation, launch Synoptic Greek Interlinear from your apps.

Installing on Ubuntu

Open the downloaded DEB using your system’s package installer. Use Ubuntu 24.04 or newer on an x86-64 computer; this package does not support ARM or Ubuntu 22.04.

What the lexical labels mean

English glosses help you inspect individual words; they do not replace passage translation or context. A leading ≈ marks an unconfirmed suggestion. Some words still have unresolved meanings or require source spelling review.
